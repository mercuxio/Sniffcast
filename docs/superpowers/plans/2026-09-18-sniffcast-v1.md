# Sniffcast v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Sniffcast, a resource-efficient macOS menubar app showing weather and AQI from Open-Meteo.

**Architecture:** Pure AppKit entry point (`main.swift` + `AppDelegate`, `.accessory` activation policy). `NSStatusItem` renders the colored menubar label; an `NSPopover` hosts a SwiftUI panel built on open and released on close. All logic that can be pure (units, AQI bands, DTO→domain mapping, refresh/alert policies, menubar formatting) lives in `Domain/` and `Data/` and is compiled directly into a host-less test bundle.

**Tech Stack:** Swift 6, AppKit, SwiftUI, Swift Charts, CoreLocation, Network, UserNotifications, ServiceManagement, Swift Testing, XcodeGen 2.46.

**Spec:** `docs/superpowers/specs/2026-09-18-sniffcast-design.md`

## Global Constraints

- macOS deployment target **15.0**; `SWIFT_VERSION = 6.0` (strict concurrency).
- No third-party dependencies.
- Agent app: `LSUIElement = YES`. App Sandbox on, with `network.client` and `personal-information.location` entitlements. Ad-hoc signing (`CODE_SIGN_IDENTITY = "-"`).
- Toolchain: every `xcodebuild` call runs with `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer` (the system's active developer dir is the CLT). Wrapped in `scripts/build.sh` / `scripts/test.sh`.
- `.xcodeproj` is generated (`xcodegen generate`) and git-ignored.
- Network: fetch in °C and km/h, `timeformat=unixtime`, `timezone=auto`; convert units locally.
- Efficiency budgets (spec §6): idle CPU ≈ 0%, idle footprint < 40 MB, no wakeups between refreshes except rotating-style timer (8 s, tolerance 0.8 s).
- Refresh interval setting: 15/30/45/60 min, default 30; tolerance = interval ÷ 6.
- Current location is the default active location.

### Task 2: Units, AQI scale, weather codes

**Files:** Create `Domain/Units.swift`, `Domain/AQIScale.swift`, `Domain/WeatherCode.swift`; Test `UnitsTests.swift`, `AQIScaleTests.swift`.

**Interfaces — Produces:**
- `enum TemperatureUnit: String, CaseIterable, Sendable { case celsius, fahrenheit }`
- `enum WindUnit: String, CaseIterable, Sendable { case kmh, mph }`
- `enum Units { static func temperature(_ celsius: Double, in: TemperatureUnit) -> Double; static func formatTemperature(_ celsius: Double, in: TemperatureUnit) -> String /* "72°" */; static func wind(_ kmh: Double, in: WindUnit) -> Double; static func formatWind(_ kmh: Double, in: WindUnit) -> String /* "8 mph" */; static func defaults(for locale: Locale) -> (TemperatureUnit, WindUnit, AQIScaleKind) }`
- `enum AQIScaleKind: String, CaseIterable, Sendable { case us, eu }`
- `enum AQIBand: Int, CaseIterable, Sendable { case good, moderate, sensitive, unhealthy, veryUnhealthy, hazardous }`
- `enum AQIScale { static func band(for: Int, scale:) -> AQIBand; static func label(for: AQIBand, scale:) -> String; static func defaultThreshold(_:) -> Int; static func rearmMargin(_:) -> Int }`
- `enum WeatherCode { static func symbol(_ code: Int, isDay: Bool) -> String; static func description(_ code: Int) -> String }`

Test cases (Swift Testing, parameterized):
- 0 °C → 32 °F; 15.5 °C → "60°" (°F), "16°" (°C); −0.4 °C → "0°" (no "−0°").
- 12.6 km/h → "8 mph", "13 km/h".
- US bands: 0,50→good; 51,100→moderate; 101,150→sensitive; 151,200→unhealthy; 201,300→veryUnhealthy; 301,500→hazardous.
- EU bands: 0,20→good; 21,40→moderate(“Fair”); 41,60→sensitive(“Moderate”); 61,80→unhealthy(“Poor”); 81,100→veryUnhealthy(“Very poor”); 101→hazardous(“Extremely poor”).
- Labels: US sensitive = "Unhealthy for sensitive groups"; EU moderate = "Fair".
- Thresholds 100/60; margins 10/5.
- Locale en_US → (fahrenheit, mph, us); en_GB → (celsius, mph, eu); de_DE → (celsius, kmh, eu); en_IN → (celsius, kmh, us).

Steps: write tests → run (fail) → implement → run (pass) → commit `feat: units, AQI scales, weather codes`.

### Task 3: Open-Meteo DTOs, mapper, client

**Files:** Create `Domain/Models.swift`, `Data/OpenMeteoDTO.swift`, `Data/SnapshotMapper.swift`, `Data/OpenMeteoClient.swift`; Test `MapperTests.swift` with fixtures `forecast_london.json`, `air_london.json`, `air_sf_nopollen.json`, `geocode_portland.json`, `error.json`.

**Interfaces — Produces:**
- `struct Coordinate: Codable, Hashable, Sendable { var latitude, longitude: Double }`
- `struct SavedLocation: Codable, Hashable, Identifiable, Sendable { var id: UUID; var name: String; var detail: String; var coordinate: Coordinate }`
- `struct GeocodeResult: Hashable, Sendable, Identifiable { var id: Int; var name: String; var detail: String; var coordinate: Coordinate }`
- `struct Snapshot: Sendable, Equatable { var fetchedAt: Date; var current: CurrentConditions; var hourly: [HourlyPoint]; var daily: [DailyPoint]; var air: AirQuality? }`
- `CurrentConditions { temperature, apparentTemperature, windSpeed: Double; humidity: Int; weatherCode: Int; isDay: Bool }` (°C, km/h)
- `HourlyPoint { time: Date; temperature: Double; weatherCode: Int; usAQI: Int?; euAQI: Int? }`
- `DailyPoint { date: Date; weatherCode: Int; high, low: Double; pollen: Pollen? }`
- `AirQuality { usAQI: Int?; euAQI: Int?; pollutants: Pollutants }`, `Pollutants { pm25, pm10, ozone, no2, so2, co: Double? }`
- `Pollen { alder, birch, grass, mugwort, olive, ragweed: Double? }` + `var entries: [(name: String, value: Double)]`
- `enum SnapshotMapper { static func decodeForecast(_ Data) throws -> ForecastResponse; static func decodeAir(_ Data) throws -> AirQualityResponse; static func decodeGeocode(_ Data) throws -> [GeocodeResult]; static func make(forecast:air:fetchedAt:) -> Snapshot }`
- `enum OpenMeteoError: Error, Equatable { case api(String), http(Int), decoding }`; `SnapshotMapper.apiError(from: Data) -> OpenMeteoError?`
- `protocol WeatherProviding: Sendable { func fetch(_: Coordinate) async throws -> Snapshot; func search(_: String) async throws -> [GeocodeResult] }`
- `struct OpenMeteoClient: WeatherProviding` with `static let sharedSession: URLSession` (URLCache 1 MB/5 MB).

Test cases:
- London forecast maps current 15.5 °C, humidity 61, code 1, isDay true; 12 hourly points; 7 daily points.
- London air: `air.usAQI == 31`, `pm25 == 8.3`; hourly points carry AQI from matching timestamps (first hourly point has non-nil `usAQI`); daily[0].pollen non-nil.
- SF air: every `daily[i].pollen == nil`.
- `make(forecast:air: nil)` → `snapshot.air == nil` and hourly AQI nil.
- Geocode Portland: first result name "Portland", detail "Oregon, United States".
- `apiError(from: error.json)` → `.api("Latitude must be in range of -90 to 90°. Given: 999.0.")`.

Steps: tests → fail → implement → pass → commit `feat: Open-Meteo client and snapshot mapping`.

### Task 4: Refresh policy, alert evaluator, menubar formatter

**Files:** Create `Domain/RefreshPolicy.swift`, `Domain/AlertEvaluator.swift`, `Domain/MenubarFormatter.swift`; Tests `RefreshPolicyTests.swift`, `AlertEvaluatorTests.swift`, `MenubarFormatterTests.swift`.

**Interfaces — Produces:**
- `enum RefreshInterval: Int, CaseIterable, Sendable { case fifteen = 15, thirty = 30, fortyFive = 45, sixty = 60; var seconds: TimeInterval }`
- `struct RefreshPolicy: Sendable { var interval: RefreshInterval; var tolerance: TimeInterval; func isDue(lastFetch: Date?, now: Date) -> Bool /* nil or age > interval */; func isDueOnPanelOpen(lastFetch:now:) -> Bool /* nil or age > 600 */; func isStale(lastFetch:now:) -> Bool /* age > 1.5×interval */; func backoff(attempt: Int) -> TimeInterval /* min(120·2^(attempt−1), interval) */ }`
- `struct AlertEvaluator: Sendable { mutating func evaluate(aqi: Int, threshold: Int, margin: Int, key: String) -> Bool }`
- `enum MenubarStyle: String, CaseIterable, Sendable { case full, compact, rotating }`
- `enum MenubarPhase: Sendable { case weather, air }`
- `struct MenubarContent: Equatable, Sendable { var symbol: String; var text: String; var aqiText: String?; var band: AQIBand?; var stale: Bool }`
- `enum MenubarFormatter { static func content(snapshot: Snapshot?, style: MenubarStyle, phase: MenubarPhase, temperatureUnit: TemperatureUnit, scale: AQIScaleKind, stale: Bool) -> MenubarContent }`

Test cases:
- For each interval: tolerance = seconds/6; `isDue` false at age = interval, true at interval+1; stale false at 1.5×interval, true just after; backoff(1)=120, (2)=240, (3)=480, (10) = interval.
- Panel open: due at 601 s, not at 599 s; nil lastFetch → due for all.
- Alerts: 90→false, 100→true, 120→false (disarmed), 95→false (not re-armed, > 90), 90→false (re-arms), 101→true. Separate keys independent.
- Formatter: nil snapshot → text "—", aqiText nil. Full → text "60°", aqiText "AQI 31", band .good. Compact → aqiText "●". Rotating weather phase → aqiText nil; air phase → symbol "aqi.medium", text "", aqiText "AQI 31". EU scale uses euAQI. Missing air → aqiText nil in every style.

Steps: tests → fail → implement → pass → commit `feat: refresh policy, alert hysteresis, menubar formatter`.

### Task 5: State stores and location provider

**Files:** Create `State/Observe.swift`, `State/AppState.swift`, `State/SettingsStore.swift`, `State/LocationsStore.swift`, `Location/LocationProvider.swift`.

**Interfaces — Produces:**
- `@MainActor func observe(_ body: @escaping @MainActor () -> Void)` — runs body, re-runs on any observed change.
- `@MainActor @Observable final class AppState { var snapshot: Snapshot?; var snapshotKey: String?; var isFetching: Bool; var isStale: Bool; var lastError: String?; var currentCoordinate: Coordinate?; var locationStatus: LocationStatus }`, `enum LocationStatus { case unknown, authorized, denied }`
- `@MainActor @Observable final class SettingsStore { menubarStyle, temperatureUnit, windUnit, aqiScale, refreshInterval, alertsEnabled, alertThreshold }` — persisted in `UserDefaults`; changing `aqiScale` resets `alertThreshold` to the scale default.
- `enum ActiveLocation: Equatable, Codable { case current, saved(UUID) }`
- `@MainActor @Observable final class LocationsStore { var saved: [SavedLocation]; var active: ActiveLocation; func add(_ GeocodeResult); func remove(id: UUID); func move(from: IndexSet, to: Int); func target(currentCoordinate: Coordinate?, locationDenied: Bool) -> LocationTarget? }`
- `struct LocationTarget: Equatable { var key: String; var name: String; var coordinate: Coordinate }` — current location key `"current"`; denied/unavailable current location falls back to `saved.first`.
- `@MainActor final class LocationProvider: NSObject, CLLocationManagerDelegate { var onUpdate: ((Coordinate) -> Void)?; var onStatus: ((LocationStatus) -> Void)?; func start(); func stop() }` — kilometer accuracy, `requestLocation()` then significant-change monitoring, emits only on > 1 km movement.
